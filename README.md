# VLM Hierarchy-Aware Fine-Tuning Under Noisy Taxonomy

Evaluating the robustness of hierarchy-aware CLIP fine-tuning when the taxonomic supervision signal is noisy.

## Overview

This project investigates whether incorporating hierarchical (taxonomy) information during vision-language model fine-tuning improves classification accuracy, and how robust this benefit is when the taxonomy contains errors. We fine-tune OpenCLIP ViT-B/32 with a multi-task objective (leaf classification + parent classification) and systematically corrupt the parent labels to simulate noisy real-world taxonomies.

### Key Research Questions

1. Does hierarchy-aware training improve leaf classification accuracy over flat fine-tuning?
2. How does the benefit degrade as taxonomy noise increases?
3. What is the optimal weighting (lambda) between leaf and parent objectives under noise?
4. Which metrics best capture the impact of noisy hierarchical supervision?

## Dataset

### Quick Start (Small Subset)

```bash
python build_dataset.py --num-coarse 15 --per-class 48
```

Creates ~3,600 images from 15 CIFAR-100 coarse groups (75 leaf classes), split 80/20.

### Full CIFAR-100 (Paper Experiments)

```bash
python build_dataset.py --num-coarse 20 --per-class 0 --use-test-split
```

Uses all 20 superclasses (100 leaf classes), all 500 train + 100 test images per class (60,000 total). The official CIFAR-100 test split is used as the test set.

### Dataset Schema

Each entry in `train.json` / `test.json`:

```json
{
  "image": "data/images/000001.jpg",
  "label": "beaver",
  "path": ["animal", "aquatic_mammals", "beaver"]
}
```

The 3-level hierarchy: **domain** -> **coarse superclass** -> **leaf class**.

## Running Experiments

### Individual Runs

```bash
# Zero-shot baseline
python zeroshot.py --no-wandb

# Flat fine-tuning
python train.py --mode flat --seed 42 --no-wandb

# Hierarchy-aware with clean taxonomy
python train.py --mode hierarchy --taxonomy clean --seed 42 --no-wandb

# Hierarchy-aware with noisy taxonomy (20% corruption)
python train.py --mode hierarchy --taxonomy noisy --noise-fraction 0.2 --seed 42 --no-wandb

# Custom lambda and noise
python train.py --mode hierarchy --taxonomy noisy --noise-fraction 0.5 --lambda-parent 0.8 --seed 123 --no-wandb
```

### Paper Sweep (Automated)

```bash
# Run all baselines across 5 seeds (~16 runs)
python run_sweep.py baselines

# Noise fraction sweep: 8 levels x 5 seeds (~40 runs)
python run_sweep.py noise

# Lambda sensitivity: 6 lambdas x 3 noise levels x 3 seeds (~54 runs)
python run_sweep.py lambda

# Everything at once
python run_sweep.py all

# Preview without running
python run_sweep.py all --dry-run

# Resume interrupted sweep (skip completed configs)
python run_sweep.py all --resume
```

### Cached Feature Noise Sweep

For report-scale noise studies on smaller GPUs, cache OpenCLIP ViT-B/32 image
features once and train a lightweight residual adapter plus classification
heads across many seeds and noise settings:

```bash
python feature_sweep.py --epochs 30 --seeds 42 123 456 ^
  --noise-fractions 0.0 0.05 0.1 0.2 0.3 0.5 0.7 1.0 ^
  --noise-types uniform in_domain cyclic ^
  --lambda-parent 1.0 --consistency-weight 0.8 --lr 0.001
```

This writes fresh rows to `runs/results.json`, then `analysis.py` can export
paper tables and degradation curves.

### Training Parameters

| Parameter | Default | Description |
|-----------|---------|-------------|
| `--epochs` | 8 | Total training epochs |
| `--batch-size` | 4 | Batch size |
| `--head-epochs` | 2 | Epochs with frozen backbone (head-only training) |
| `--head-lr` | 1e-4 | Learning rate for classification heads |
| `--backbone-lr` | 1e-5 | Learning rate for ViT backbone (after unfreezing) |
| `--lambda-parent` | 0.4 | Weight of parent classification loss |
| `--noise-fraction` | 0.2 | Fraction of parent labels to corrupt |
| `--val-fraction` | 0.1 | Validation holdout from training set |

## Metrics

| Metric | Description |
|--------|-------------|
| **Leaf Accuracy** | Top-1 classification accuracy on leaf (fine) classes |
| **Top-5 Accuracy** | True label in top-5 predictions |
| **Parent Accuracy** | Accuracy at the coarse superclass level (from head or derived) |
| **Hierarchical Distance** | Mean tree distance between predicted and true leaves (0/2/4/6 scale) |
| **Severity-Weighted Acc** | 1.0 correct, 0.5 same-parent mistake, 0.0 cross-parent mistake |
| **ECE** | Expected Calibration Error (15-bin equal-width) |

## Architecture

- **Backbone:** OpenCLIP ViT-B/32 (OpenAI pretrained weights)
- **Leaf head:** Linear(512 -> num_leaf_classes)
- **Parent head:** Linear(512 -> num_parent_classes) -- hierarchy mode only
- **Loss:** `CE_leaf + lambda * CE_parent`
- **Taxonomy noise:** Per-sample uniform random parent label corruption on training set only; validation and test always use ground-truth taxonomy
